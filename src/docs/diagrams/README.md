## Cómo visualizar

Estos diagramas están escritos en **Mermaid**, un lenguaje de diagramas basado en texto.

### Opciones para visualizar:

1. **GitHub / GitLab**: Renderiza Mermaid automáticamente en archivos `.md`
2. **VS Code**: Instalar extensión "Markdown Preview Mermaid Support"
3. **Online**: https://mermaid.live (copiar y pegar el código)
